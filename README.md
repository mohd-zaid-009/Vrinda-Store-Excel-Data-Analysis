# Vrinda Store Data Analysis – Excel Dashboard

This project is a sales and customer data analysis project built in **Microsoft Excel** using the Vrinda Store 2022 dataset.

The main goal of the project was to take raw store data, analyze it from different business perspectives, and turn the results into an interactive and easy-to-understand dashboard.

## Project Overview

In this project, I worked on the raw dataset and created different analysis views to understand sales performance, customers, order status, states, age groups, and sales channels.

The workbook includes analysis using **PivotTables, PivotCharts, filters/slicers, and Excel-based data analysis techniques**.

## What I Analyzed

- Monthly **Sales vs Orders** performance
- Sales contribution by **Gender**
- **Order Status** such as Delivered, Returned, Cancelled, and Refunded
- **Top 5 States by Sales**
- Customer analysis using **Age Group and Gender**
- Order distribution across different **Sales Channels**
- Business questions and insights in a dedicated **Q&A** sheet

## Dashboard

The final dashboard brings the major findings together in a visual format so that the data can be understood quickly.

## Key Insights

Some of the major insights identified during the analysis include:

- **March** was one of the strongest months in terms of sales and order volume.
- **Women customers** contributed more to total sales than men in the analyzed dataset.
- **Delivered** was the most common order status.
- **Maharashtra** was the highest-selling state among the top states analyzed.
- **Amazon** was the leading sales channel by order volume.
- The customer analysis showed differences across **age groups and gender**, which can be useful for targeted marketing.

## Workbook Structure

The Excel workbook contains the raw data along with separate analysis sheets and the dashboard.

- `Vrinda Store Report 2022` – Main dashboard
- `Sales VS Orders` – Monthly sales and order analysis
- `Men VS Women` – Gender-wise sales analysis
- `Order Status` – Order status analysis
- `Top 5 Customers` – Top states analysis (sheet name retained from the workbook)
- `Age and Gender` – Age-group and gender analysis
- `Channels` – Sales channel analysis
- `Q-A` – Business questions and answers
- `VAStra Store` –Raw dataset

## Business Questions

The Q&A section was created to connect the analysis with practical business questions, for example:

- Which month generated the highest sales?
- Which month had the highest number of orders?
- Which gender contributed more to total sales?
- Which state generated the highest sales?
- What is the most common order status?
- Which sales channel had the highest number of orders?
- Which age group represents the largest customer segment?
